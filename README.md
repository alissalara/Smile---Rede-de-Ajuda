Smile — Rede de Ajuda 💛

Cuidar de pessoas é transformar vidas.

Sobre o projeto

A Smile é um projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS). Sua proposta é apresentar uma organização sem fins lucrativos dedicada à promoção do cuidado, da solidariedade e da inclusão social.

A iniciativa prevê visitas a instituições de acolhimento de crianças e idosos, com participação de voluntários e profissionais de diferentes áreas, além de campanhas de arrecadação de roupas, brinquedos e recursos financeiros.

Objetivos

- Divulgar as iniciativas sociais da Smile.
- Incentivar o voluntariado e as doações.
- Facilitar o acesso às informações da organização.
- Desenvolver uma interface responsiva e acessível.
- Aplicar conhecimentos de desenvolvimento web e versionamento de código.

Tecnologias utilizadas

- HTML5: estrutura semântica das páginas.
- CSS3: identidade visual, responsividade e estilos.
- JavaScript: navegação dinâmica, validação de formulários e interatividade.
- Chart.js: visualização gráfica de informações.
- Git e GitHub: controle de versões e publicação do código.

Estrutura do projeto

- "html/" — páginas HTML.
- "css/" — arquivos de estilos.
- "js/" — scripts de navegação, formulários e funcionalidades.
- "img/" — recursos visuais e logotipo.
- "README.md" — documentação do projeto.

Funcionalidades

O site apresenta informações institucionais, iniciativas sociais e opções de engajamento. Utiliza navegação dinâmica no estilo SPA (Single Page Application), menu responsivo e validação de campos do formulário com mensagens de erro.

O formulário é demonstrativo e ainda não envia ou armazena cadastros reais.

Acessibilidade

Foram adotadas práticas como uso de elementos semânticos, textos alternativos para imagens, identificação dos campos por rótulos e navegação por teclado.

Também foi desenvolvido um link para permitir que usuários de teclado avancem diretamente ao conteúdo principal.

Versionamento e Git Flow

O projeto utiliza Git e GitHub para registrar alterações e organizar o desenvolvimento.

Foram utilizadas as seguintes branches:

- "main": versão principal do projeto.
- "develop": integração das alterações em desenvolvimento.
- "feature/melhoria-acessibilidade": implementação de uma melhoria de navegação por teclado.

A melhoria foi registrada com um commit semântico, integrada à branch "develop" e posteriormente à "main".

Esse processo permitiu praticar criação de branches, commits, publicação e merge.

Desenvolvimento profissional

O projeto Smile representa uma experiência prática de aprendizagem em desenvolvimento web. Sua construção contribuiu para o aprimoramento de habilidades em organização de arquivos, programação, acessibilidade, depuração de erros e controle de versões.
